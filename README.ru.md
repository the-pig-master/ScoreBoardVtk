# ScoreBoardVtk

`ScoreBoardVtk` — это современная версия на `C# / .NET 8` для управления спортивным табло, переписанная с legacy-приложения.

Проект ориентирован на работу с реальным физическим табло через последовательный порт и включает:

- `WPF`-приложение для оператора,
- `CMD`-утилиту для поиска `COM`-порта и проверки сигнала,
- общий слой `Core` с матчевой логикой, протоколом, настройками и runtime,
- набор unit-тестов для критичной логики.

## Что делает проект

Приложение предназначено для управления спортивным табло и рабочим местом оператора.

Поддерживаются следующие сценарии:

- режим баскетбола,
- режим волейбола,
- обмен с контроллером табло через последовательный порт,
- управление счетом и фолами / сетами,
- основной игровой таймер,
- таймер броска `24 / 14`,
- ручной звуковой сигнал,
- бегущая строка,
- горячие клавиши для основных операторских действий,
- хранение настроек в JSON-файлах.

## Структура solution

В solution входят следующие проекты:

- `ScoreBoardVtk.Core`
  - доменные модели, логика controller, протокол, транспорты, настройки, runtime
- `ScoreBoardVtk.Wpf`
  - настольный интерфейс оператора
- `ScoreBoardVtk.Cmd`
  - консольная утилита для диагностики `COM`-портов и проверки сигнала
- `ScoreBoardVtk.Tests`
  - unit-тесты

## Основной функционал

### Баскетбол

- управление счетом хозяев и гостей,
- счетчики фолов,
- управление четвертями и овертаймом,
- основной таймер с обратным отсчетом,
- настраиваемый пресет основного времени,
- настраиваемый пресет овертайма,
- запуск / остановка таймера `24`,
- кнопки `Set 24`, `Set 14`, `Run 24`, `Run 14`,
- предупреждение при смене периода, если время еще не закончилось,
- сброс только таймеров,
- ручная установка счета, фолов, периода, времени и `24` через отдельное окно.

### Волейбол

- управление счетом хозяев и гостей,
- переход по сетам,
- счетчики сетов.

### Функции оператора

- бегущая строка,
- ручной звуковой сигнал,
- настройка горячих клавиш на вкладке настроек,
- отображение назначенных клавиш прямо на кнопках основного экрана.

### Технические возможности

- формирование legacy-пакетов `AT+GD`,
- `CRC16`,
- поддержка `CP1251` для старого протокола устройства,
- профили запуска `Hardware`, `Mock`, `Development`,
- встроенный `MOCK` transport для тестирования без реального железа,
- elapsed-time логика баскетбольных таймеров для более точного хода времени.

## Файлы конфигурации

Проект использует 2 JSON-файла.

### `hostsettings.json`

Расположение для WPF:

- `ScoreBoardVtk.Wpf\hostsettings.json`

Назначение:

- выбор профиля запуска,
- настройка runtime-интервалов,
- указание файла игровых настроек.

Поддерживаемые профили:

- `Hardware`
  - доступны только реальные последовательные порты
- `Mock`
  - доступен только встроенный порт `MOCK`
- `Development`
  - доступны и реальные последовательные порты, и `MOCK`

Значение по умолчанию:

- `Development`

### `settings.json`

Расположение для WPF:

- `ScoreBoardVtk.Wpf\settings.json`

Назначение:

- выбранный `COM`-порт,
- игровой режим,
- пресеты времени,
- длительности сигналов,
- горячие клавиши,
- настройки бегущей строки,
- режим отображения фолов.

Важно:

- настройки на вкладке `Settings` работают в staged-режиме,
- изменения применяются только после нажатия `Apply`.

## Как пользоваться WPF-приложением

### Базовый порядок работы

1. Открой вкладку `Settings`.
2. Выбери нужный `COM`-порт.
3. Установи нужный игровой режим и пресеты времени.
4. Нажми `Apply`.
5. Открой порт.
6. Перейди на вкладку `Game` и управляй табло.

### Работа в баскетболе

Основные кнопки:

- `Start / Stop`
  - запускает или останавливает основной игровой таймер
- `Signal`
  - ручной звуковой сигнал, пока кнопка удерживается
- `Period / Set`
  - меняет четверть
  - если время в баскетболе еще не истекло, появляется окно с предупреждением
- `Reset`
  - сбрасывает только таймеры
- `Set`
  - открывает окно ручной установки значений табло

Управление `24` секундами:

- `Start / Stop`
  - запускает или останавливает текущее значение таймера броска
- `Run 24`
  - устанавливает `24` и сразу запускает таймер
- `Run 14`
  - устанавливает `14` и сразу запускает таймер
- `Set 24`
  - устанавливает `24` без запуска
- `Set 14`
  - устанавливает `14` без запуска

Управление счетом:

- счет хозяев `+1 / -1`
- счет гостей `+1 / -1`
- фолы хозяев `+1 / -1`
- фолы гостей `+1 / -1`

### Окно ручной установки значений

Окно `Set` позволяет вручную задать:

- счет хозяев,
- счет гостей,
- фолы / сеты хозяев,
- фолы / сеты гостей,
- номер периода,
- основное игровое время,
- время таймера `24`.

В окне также есть кнопка `Reset All`, которая сбрасывает только поля этого окна в стандартные значения.
Изменения применяются только после нажатия `OK`.

### Бегущая строка

В нижней части вкладки `Game` можно:

- включить или выключить бегущую строку,
- редактировать текст, который отправляется на табло.

## Горячие клавиши

Горячие клавиши настраиваются на вкладке `Settings`.

Поддерживаемые действия:

- старт / стоп игрового таймера,
- старт / стоп таймера `24`,
- `Set 24`,
- `Set 14`,
- `Run 24`,
- `Run 14`,
- счет хозяев `+1 / -1`,
- счет гостей `+1 / -1`,
- фолы хозяев `+1 / -1`,
- фолы гостей `+1 / -1`.

Особенности:

- горячие клавиши работают на вкладке `Game`,
- они не срабатывают, когда курсор стоит в текстовом поле или `ComboBox`,
- назначенная клавиша отображается в скобках прямо на соответствующей кнопке.

## CMD-утилита

Консольный проект предназначен для диагностики и быстрой проверки оборудования.

Поддерживаемые команды:

- `list`
  - выводит список всех доступных `COM`-портов
- `buzz <COMx>`
  - отправляет звуковой сигнал длительностью `0.3` секунды на указанный порт
- `scan-all`
  - по очереди отправляет тестовый сигнал на все `COM`-порты с паузой `1` секунда
- `watch`
  - отслеживает подключение и отключение портов

Примеры:

```powershell
dotnet run --project C:\WORK\Repositories\ScoreBoardVtk\ScoreBoardVtk.Cmd\ScoreBoardVtk.Cmd.csproj -- list
dotnet run --project C:\WORK\Repositories\ScoreBoardVtk\ScoreBoardVtk.Cmd\ScoreBoardVtk.Cmd.csproj -- buzz COM3
dotnet run --project C:\WORK\Repositories\ScoreBoardVtk\ScoreBoardVtk.Cmd\ScoreBoardVtk.Cmd.csproj -- buzz MOCK
dotnet run --project C:\WORK\Repositories\ScoreBoardVtk\ScoreBoardVtk.Cmd\ScoreBoardVtk.Cmd.csproj -- scan-all
dotnet run --project C:\WORK\Repositories\ScoreBoardVtk\ScoreBoardVtk.Cmd\ScoreBoardVtk.Cmd.csproj -- watch
```

Интерактивный режим:

- запусти CMD-приложение без аргументов,
- используй клавиатурное меню со стрелками и `Enter`.

Важное замечание по безопасности:

- `buzz` и `scan-all` отправляют тот же legacy game packet с активным флагом ручного сигнала,
- не используй `scan-all` во время живой игры, если изменение состояния табло нежелательно.

## Примечания по железу и протоколу

Проект сохраняет старую модель обмена с табло и формат пакетов, но окончательную валидацию все равно нужно делать на реальном контроллере табло.

Важно:

- оригинальная старая система использовала низкоуровневую работу с последовательным портом / `RS-485`,
- текущий проект воспроизводит игровую логику и генерацию payload,
- совместимость с реальным устройством необходимо проверять на целевом оборудовании.
